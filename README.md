# Relay

A webhook delivery console built to learn frontend engineering with React,
TypeScript, and Vite. Currently displays a page heading and a delivery-list
placeholder.

## Run locally

Use Node.js 24 and npm.

```sh
npm ci
npx vite
```

Open the local URL printed by Vite.

## Check and build

```sh
npx tsc         # Check TypeScript types
npx vite build  # Build production files into dist/
```
